## Cómo se clasifica cada elemento

| Etiqueta | Significado |
|---|---|
| **Implementado** | Existe en el código, tiene pruebas o validación manual y el autor lo aprobó. |
| **Parcial** | Existe una versión reducida aprobada para el MVP (por ejemplo, el dashboard mínimo). |
| **Pendiente** | Está planificado en el SPEC para la Semana 5 o 6 (§17.2) y todavía no se ha construido. |
| **Trabajo futuro** | Está fuera del alcance de esta versión o depende del piloto. No hay fecha comprometida. |

## Advertencia académica (riesgo R-01 del SPEC)

Los documentos de la tesis (`investigacion_completa.md` y `resumen_requerimientos.md`) describen un piloto, una capacitación y una reducción de tiempos como hechos. **Con este software todavía no se ha hecho un piloto en talleres reales.** Según la decisión H-3, esos capítulos se ajustan con los datos del piloto. Por eso esta documentación no presenta ningún resultado de campo como si ya existiera.
